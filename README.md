# 锋芒标签打印

面向 Windows 的桌面标签设计与打印工具。选模板 → 改内容 → 直接出标，同时给需要的人留了完整的画布编辑能力。

![模板库](docs/screenshot-gallery.png)

## 它解决什么

大多数标签软件要么太重（BarTender 那一类），要么只能改固定几项。这个工具的做法是：

- **模板优先**：内置 19 套常用版式，点一下直接应用，不用从白纸开始。
- **全部可改**：尺寸、字段、字体、颜色、条码、二维码、表格、图层都能改。
- **两种出标方式**：标签机走原生指令（ZPL / TSPL）RAW 直出；普通打印机走系统打印。
- **所见即所得**：设计器、预览、打印指令来自同一套渲染，避免「屏幕好看、打出来跑偏」。

## 功能

**模板（19 套 / 6 类）**

物流快递、仓储库位、零售价签、食品生鲜、办公资产、工业制造。每套都带示例数据和完整字段，点击即用。

**设计器**

- 元素：文字、条码（Code128 / EAN-13 / Code39 / ITF-14）、二维码、图片、矩形、线条、表格
- 毫米级画布、标尺、1 mm 吸附、元素对齐参考线
- 拖动 / 缩放 / 框选 / 多选 / 旋转 / 锁定 / 图层排序
- 撤销重做（60 步）、复制、方向键微调、双击改字
- 纸宽 / 纸高 / 间隙 / 203·300·600 dpi / 连续纸
- 19 种常用尺寸预设（覆盖全部内置模板），也可自定义宽高

**数据**

- `{{字段}}` 变量绑定，示例值实时预览
- 流水号（起始、步长、位数）
- CSV / TSV 导入，多行数据逐条预览与批量打印

**打印**

- 标签机直打：模板 → 1-bit 位图 → ZPL / TSPL → Windows 打印队列 RAW 直出
- 系统打印：按目标 dpi 渲染 PNG，纸张锁定为标签实际尺寸，不按 A4 缩放
- 导出：PNG 图片、ZPL 指令文件
- 浓度、速度、纵向偏移、份数

**其他**

- 「我的模板」本地保存，重启不丢
- 中文字体转位图输出，不依赖打印机字库
- 全本地运行，无账号、无上传
- 自绘标题栏（无系统边框），浅色主题

## 安全

- 渲染进程开启 `contextIsolation` 与 `sandbox`，关闭 `nodeIntegration`，只通过 preload 暴露白名单 API
- 每个 IPC 调用都校验来源窗口，打印份数、纸张尺寸等参数做范围限制
- 页面启用 CSP，禁止外部脚本、外部页面跳转与新窗口
- 不发起网络请求、不上传数据；模板与设置只保存在本机用户目录

## 开发

```bash
npm install
npm run dev      # 浏览器调试（http://localhost:5178）
npm run app      # 构建并以 Electron 启动
npm run build    # 类型检查 + 生产构建
npm run check    # 打印指令与 IPC 契约自检

```

环境：Node ≥ 20、Windows 10/11。

## 打印原理

标签机是「指令机」，用 PDF 打印会整页栅格化，出标慢且条码容易糊。这里的做法是：

1. 用 Canvas 在目标 dpi 下把整张标签渲染成位图（文本、条码、二维码、图片都在这一层对齐）；
2. 阈值化为 1-bit，按行打包；
3. 生成 `^GFA`（ZPL）或 `BITMAP`（TSPL）指令；
4. 通过 `winspool` 的 `StartDocPrinter(RAW)` 直接投递到打印队列。

整张位图的代价是数据量比原生条码指令大，但换来的是**所见即所得**：反白文字、叠加图形、中文字体都不会跑偏。

## 已知限制

- 未在真实标签机上调校过：走纸偏移、浓度、速度需要按机型微调。
- ESC/POS 未实现（票据机可先用系统打印）。
- 表格只支持规整行列，不支持合并单元格。
- 旋转元素在画布上按外接框选中，旋转后命中区域略大。
